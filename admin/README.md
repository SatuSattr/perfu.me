# Admin — Perfu.me (Laravel)

Folder ini disiapkan untuk project Laravel dashboard admin.

Belum ada instalasi — nantinya akan diisi dengan:

``bash
composer create-project laravel/laravel .
cp .env.example .env
php artisan key:generate
php artisan migrate
``n
Fitur yang akan ada: autentikasi admin, CRUD produk/varian, manajemen pesanan & stok, laporan. Terhubung ke API yang dikonsumsi oleh /store.
